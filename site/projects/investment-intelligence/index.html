Investment Intelligence System

Combining six kinds of market evidence into explainable research, without hiding uncertainty or collapsing everything into one score.

View on GitHub

The problem

Signals disagree, and a single score hides it

Trend, fundamentals, institutional flow, technicals, tape and sentiment often point in different directions. Averaging them into one number throws away the most useful information: where they conflict, and why.

Architecture

Evidence first, explanation second

The six engines

Select an engine

Every engine returns the same shape: direction, strength, evidence, time horizon, data quality and what would invalidate it.

What it does
Why it matters

Design decisions

One result contract for every engine

A shared schema lets the synthesis compare engines directly, and makes a missing or low-quality input visible instead of silent.

Treat disagreement as data

Conflicts are surfaced and weighed by time horizon, signal dependence and data freshness, not averaged away.

Constrain the language layer

The explanation step can only use numbers the engines produced, so the report stays traceable to evidence.

Be honest about status

Heuristic scores are not calibrated probabilities. The system is a research tool, not a trading system, and has not yet shown predictive edge.
